# Fit Fusion App

وب‌اپ همراه تمرین برای دوره‌ی ۲۴ هفته‌ای Fit Fusion — نسخه‌ی فاز ۱ / روز ۱.

## اجرا روی سیستم خودت
```bash
npm install
npm run dev
```

## Build برای انتشار
```bash
npm run build
```
خروجی توی پوشه‌ی `dist/` ساخته می‌شه.

## دیپلوی
این پروژه با Vercel و Netlify سازگاره (به‌محض اتصال ریپو، به‌صورت خودکار build و publish می‌کنن).
